# Project vendor marks

These locally bundled SVG silhouettes identify the silicon manufacturer. Model labels and missing-file indicators are separate UI elements. No network requests are made at runtime.

`chip.svg` is an original 24 × 24 outline icon (MIT), with a 1.5 px stroke, rounded joins and four-sided pins, matching the editor reference. Use it for the device entry or an unspecified chip. `ChipMark` provides a compact vendor mark for labels; `ProjectIcon` retains the larger model badge used in project lists.

- **Kendryte (Canaan)**: symbol paths from the [official developer community logo](https://www.kendryte.com/img/logo.92f92d76.svg). The wordmarks and separator are omitted; the symbol geometry is unchanged.
- **STMicroelectronics**: [Simple Icons SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/stmicroelectronics.svg), checked against the [ST trademark list](https://www.st.com/content/st_com/en/about/st-trademark-list.html).
- **Espressif**: [Simple Icons SVG](https://github.com/simple-icons/simple-icons/blob/develop/icons/espressif.svg), checked against the [official logo guidelines](https://www.espressif.com/en/about-espressif/logo-guidelines).

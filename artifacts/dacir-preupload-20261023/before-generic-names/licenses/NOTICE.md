Copyright notices on retained files are preserved. On 2026-10-23 this distribution omitted the unused Emm V5 device driver and its disabled configuration/include entries; components.lock.json records the upstream base and template-sources.json records the resulting files. Template README files are adapted for standalone use; font provenance lock files are included with the notices. Teaching templates, HAL timebase and NUN_DX use AGPL-3.0-only. Support headers copied from firmware/library retain that directory's AGPL-3.0-only license; runtime.c and the linker script retain the DACIR repository MIT license; glyph licenses remain under drivers/nun-dx/licenses. The Nodu CMake adapter is MIT. ST HAL/CMSIS is supplied by the separately licensed Nodu toolkit. This snapshot does not bundle the DACIR simulator or desktop shell.

# 双栏设计 · 第二轮

日期：2026-10-22。用户认可双栏方向，要求继续提高紧凑度并给出三个版本，关注视觉平衡和信息密度。本轮只修改独立设计稿，没有继续修改应用代码。

三稿均使用相同内容、芯片型号、颜色、13 px 正文和 1:1 绘制比例。与第一轮 A 方案 788 × 450 px 比较面积，而不是用缩小截图或缩小文字制造紧凑感。

## 视觉取舍

01：标题、主体、底部边界明确；左侧四行与右侧四行对齐；侧栏和表单上边距相同，操作按钮与输入框右边缘对齐。这是本轮推荐方向，密度提升但没有压缩文字可读性。

02：缩小侧栏和字段间距，去掉整块蓝色选中背景及贯穿全宽的按钮栏。视线更集中，工具感更强；代价是更小的点击高度和较短的路径可见宽度。

03：取消贯穿顶部的标题区，标题移到左栏。右栏全部标签放在控件上方，避免混合标签对齐。名称和位置保留长输入框，型号与模板并列，从结构上减少纵向占用。代价是两栏顶部不再共享同一标题行，习惯传统对话框的人需要适应。

所有版本：不添加说明文案、二级标题、重复路径预览或参数卡片；浏览图标合并到位置输入框尾部；关闭图标、浏览按钮与选项各自拥有独立交互区域。按钮默认/悬停/按下/焦点/禁用/执行中沿用第一轮状态稿，尺寸随版本调整。矢量稿不代表键盘与交互功能已经实现，待选稿后实现并验证。

`index.html` 提供三个版本、并排对比与深浅主题。SVG 为原始可编辑稿，PNG 为浏览器截图。

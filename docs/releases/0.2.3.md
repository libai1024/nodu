2026-10-31。此版发布 Windows x64 完整离线安装包；macOS Apple Silicon 继续使用 [0.2.2](0.2.2.md)，没有新的 Intel Mac 或 Linux 安装包。

## 使用

下载 setup.exe 和全部三个分卷，保持原文件名，放在同一目录后运行安装器。不需单独解压分卷，也不需下载工具链。默认安装至 D:\Nodu，只允许非 C 盘；用户数据与缓存留在 Data。设备驱动由 Windows 管理系统目录。

包含 STM32 工具链、CubeF1/F4 SDK、OpenOCD/stm32flash、Arduino CLI 1.5.1、ESP32 Core 3.3.12、C3/S3 支持、11 个常用库、Arduino 语言服务及 ST-LINK/CH343 驱动。首次打开 ESP 工程会本地解包环境；之后复用环境与编译缓存。AI 服务及额外库下载需要网络。

本版整合 Keil 工程生成与自动维护、DACIR 模板、ESP 仿真包导出，并包含 Windows 剪切、终端、环境缓存和界面修复。

## 成品验收

- 从干净提交在 Windows 本地构建，正式 full 资源校验通过；实际安装至独立 D 盘目录，初始 Data 为空。
- S3 COM4：两份不同固件分别编译、烧写、复位运行，识别 16 MB Flash / 8 MB OPI PSRAM；ASCII、中文、4200 字符回显及串口重开通信通过。
- C3/S3：同一个工程引用全部 11 个常用库，编译、故意错误检测、修复重编译通过。重开环境检查约 1.35 / 1.37 秒。
- C3/S3 语言服务：补全、悬停、定义跳转、未保存诊断、Unicode 编辑与整页替换后的映射通过。
- F103：五组成功编译、错误及恢复、clangd 补全/定义/诊断通过；最终程序启动及本地 Data 目录检查通过。没有进行 STM32 实体烧写。
- Arduino 编译与 S3 真板测试阻断 Nodu/CLI 外网；STM32 测试阻断列出的构建工具外网，PATH 仅含 Windows 系统目录。动态阻断规则已移除。

## 范围与限制

C3 没有实体板验收；S3 真板验证限本次 COM/CH343 接口和内存配置。其他 USB 串口芯片需匹配驱动。Windows 11 没有另行实测。Arduino IDE 2.3.7 的 profile 交接限制仍在，不能承诺原项目无条件直接编译。语言服务在整页替换并保存后的重建，本机约 33–35 秒，普通输入与悬停的测量见验收记录。

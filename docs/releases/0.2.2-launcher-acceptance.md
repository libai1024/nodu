# 0.2.2 欢迎页整合与验收

## 整合原因

此前候选安装包包含已提交的工作台版本，但未包含 Kimi 在 10 月 24 日 13 点后继续完成的未提交改动。集成时仅核对已提交分支，遗漏了这部分后续成果，因此出现欢迎页仍为旧版的情况，并非应用缓存未刷新。

本轮从原开发工作树核对并移植后续工作台、项目图标和工程身份缓存改动，再按最新要求调整为接近 IDEA 欢迎页的三个主入口。保留集成分支已有的路径授权、示例过滤、有界文件读取和失败处理。原工作树及其未提交文件保留，未通过覆盖、清理或重置原现场完成整合。旧 `ded6386` 候选没有发布，保留为 `v0.2.2-candidate-ded6386` 标签；最终 `v0.2.2` 指向 `026c34613d88f5d696cc750a3a4866a7a8b2dcc9`。

## 当前窗口规格

欢迎窗口调整为固定 960×680，最小和最大尺寸一致，不允许调整大小、最大化或全屏；仅在屏幕可用区域不足时按可用区域缩小。工程窗口维持原有行为。侧栏与主入口“打开项目”均已去掉省略号。包含固定窗口方法边界用例的 `launcher.cjs` 与 `launcher-view.cjs` 共 39 项测试全部通过，TypeScript 编译与 Electron 构建均零错误。

## 最终安装包验收

macOS 与 Windows 最终包均来自源码 [`026c34613d88f5d696cc750a3a4866a7a8b2dcc9`](https://github.com/libai1024/nodu/commit/026c34613d88f5d696cc750a3a4866a7a8b2dcc9)，两份 manifest 记录 `sourceDirty=false`，与 `v0.2.2` 标签一致。此后的 `main` 只补录文档，安装包来源提交保持不变。三个应用附件已重新计算大小与 SHA-256，与 manifest 一致，完整摘要见 [发布记录](0.2.2.md#安装包与校验)。

### macOS Apple Silicon

- `codesign --deep --strict` 完整性校验与 `hdiutil` 磁盘映像校验通过。包采用 ad-hoc 签名，未完成 Developer ID 签名或公证。

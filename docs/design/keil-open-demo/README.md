# 项目打开方式演示

独立 HTML 原型，展示同一个 STM32 项目选择 Nodu 或 Keil 5 打开的交互。直接打开 `index.html`，或在仓库根目录运行：

```sh
python3 -m http.server 8781 --bind 127.0.0.1 --directory docs/design
```

浏览器访问 `http://127.0.0.1:8781/keil-open-demo/`。

## 体验流程

1. 点击 LED 闪烁项目右侧的下拉箭头，选择「在 Keil 5 中打开」。
2. 首次模拟准备约 2 秒后进入编辑预览；期间可取消。
3. 修改 `main.c` 并保存，再切换打开方式；两种预览读取同一份示例代码。
4. 返回项目列表，主按钮显示这个项目上次选择的工具。刷新页面后仍保留选择与示例编辑。
5. 勾选「模拟未安装 Keil」可体验缺失环境提示，并选择继续用 Nodu 打开。
6. 「重置演示」清除本演示的示例修改和选择，恢复三个初始项目。主题保留。

支持深浅主题、搜索及空结果、键盘菜单（方向键、Home / End、Escape）和 Ctrl / Command + S 保存。

## 边界

- 本页面不启动 Nodu 或 Keil，不转换真实工程、不编译、不烧写，也不读写显示的 D 盘路径。
- 编辑与偏好只存于本浏览器、当前站点的 `nodu-keil-open-demo-v1` 存储项；存储不可用时保留在当前页面。
- Keil 页面为流程演示编辑器，不是 Keil 软件截图或对其界面的完整复刻。
- 三个项目均为示例。清空浏览器站点数据也会删除示例修改。
- 标志复制自仓库 `brand/assets/mark-small.svg`，采用 Nodu 品牌主色和工作台风格；此原型使用系统字体，辅助文字和状态色为便于阅读作局部调整。浅色菜单保持品牌规范的白色底。没有外部字体、脚本或网络依赖。

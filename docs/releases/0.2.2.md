# Nodu 0.2.2

本版集中整合 STM32 HAL C 开发、AI 教学、独立工作台与极简编辑界面。应用版本、仓库 `VERSION` 与 Release 标签统一为 `0.2.2`。

## 本版内容

- 独立工作台：最近项目、新建、打开、搜索和参考项目副本；表单错误、操作失败与加载状态分别处理。
- 极简界面：常驻左侧功能栏、顶部项目搜索、右上角简洁设置，保留深浅主题；底部圆形动作按钮支持长按选择编译、烧录或编译并烧录。
- STM32：HAL C 工程、clangd、固件产物定位、ST-LINK/串口 ISP 配置、构建与烧录进度；修复取消后遗留 BOOT 引导、切换方式无响应及旧构建误用等边界。
- AI 教学：目标计划、下方范字、行/片段反馈、高光批注、文件跳转、暂停恢复和跨编辑器任务浮窗；支持修改步骤。
- K210：保留 MicroPython 运行、REPL、板端文件与相机工作流。

## 安装包与签名

本轮交付目标为 macOS Apple Silicon（最低构建目标 macOS 15），并尝试在局域网 Windows 主机上构建 x64 版本。

**附件清单及摘要须在本轮构建验收后填入；此处不代表安装包已经发布。** Windows 是否提供以实际 Release 附件为准，不以历史版本文件替代。当前本地打包采用 ad-hoc 签名，未完成 Apple Developer ID 签名或公证。

安装方法见 [README](../../README.md#安装)。使用正确架构的附件，保持应用与随包工具完整，不混用其他版本的工具目录。

## 验证情况

本版源码合入前的离线回归：437 项，**435 通过、2 跳过、0 失败**；TypeScript 编译、Electron 构建及品牌检查通过。跳过项分别缺少开发版设备二进制、固定版本 MaixPy 示例源仓库，未计作通过。

已有实际 Electron 界面验证及真实模型教学记录；STM32F103 的编译、备份、ST-LINK 写入与读回、运行和新串口输出已在前期开发中实测。F407 的 ST-LINK 路径亦有历史实测。**这些属于前期开发证据，不代表本次最终安装包已重新通过全部硬件验收。** 本轮安装包的启动与运行结果应另列在 Release 附件说明中。

验收材料：[界面与回归](../design/minimal-ide/IMPLEMENTATION-2026-10-24.md)、[教学与设备记录](../ai-tutor/NIGHTLY-2026-10-24.md)、[工作台](../ai-tutor/WORKBENCH-ACCEPTANCE-2026-10-24.md)、[任务浮窗](../ai-tutor/TASK-OVERLAY-IMPLEMENTATION-2026-10-24.md)。

## 已知范围

- AI 评价不能代替编译与真机运行；模型可能给出错误 API，缺上下文时需要核对工程声明。
- F407 SHT30 课程有离线构建与纯函数检查，尚未证明真实传感器通信。
- Windows 的教学纯函数执行暂不可用；Intel Mac 的完整应用验证和 Linux 分发尚未完成。
- 账号、计费、并发控制与电脑绑定授权仍处于 [0.3 设计](../0.3/README.md)阶段。
- 本次不启用 CI/CD。历史工作流已移为停用参考文件，不会随推送自动运行。

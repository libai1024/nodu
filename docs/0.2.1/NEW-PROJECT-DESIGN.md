## 调研

| 产品 | 官方流程 | 对本项目的启发 |

| [IntelliJ IDEA](https://www.jetbrains.com/help/idea/new-project-wizard.html) | 左侧选语言或生成器，右侧填名称、位置、构建系统和 JDK，直接创建 | 稳定的双栏布局；切换类型不丢失名称和路径 |

## 方案比较与选择

| 方案 | 优点 | 代价 | 决定 |
| --- | --- | --- | --- |
| 双栏单页：左系列、右表单 | 所有必要信息同时可见；系列间切换快；型号容易扩展 | 比命令面板占用更多空间 | 采用 |
| 多步向导：芯片 → 模板 → 位置 | 每步内容少 | 需要来回检查，增加点击和标题 | 不采用 |
| 命令面板连续选择 | 适合键盘熟练用户 | 不方便同时比较型号、路径和模板 | 不作为主入口 |

## 创建契约

- K210：MaixPy，生成 main.py 与项目元数据，不指定摄像头、显示屏或开发板。
- STM32F103：STM32F103C8T6；STM32F407：STM32F407ZGT6。使用新的芯片默认包和内部 HSI 时钟，不继承探索者、蓝板等板型假设。保留历史板卡包以兼容已建工程。提供空项目和串口输出；不提供未经硬件核实的 LED 模板。
- ESP32：ESP-IDF C 项目，型号映射到官方 IDF_TARGET；生成 CMake、main、sdkconfig.defaults 和任务配置，不指定开发板接线。ESP-IDF 工具链由本机环境提供，不把 STM32 工具链误用于 ESP32。工具链安装、真机烧录不属于新建对话框本身。
- 所有创建均校验名称、型号、模板和绝对父目录，拒绝覆盖既有目录。K210/ESP32 创建不启动 STM32 sidecar。

ESP-IDF 目录格式与目标约定参考：[官方构建系统](https://docs.espressif.com/projects/esp-idf/en/stable/esp32/api-guides/build-system.html)。

# Nodu 0.3 实施路线与验收

本文件描述下一阶段开发，不表示本轮已开发或通过以下测试。顺序依赖优先于日历；AI 教学由 Claude 继续开发，账号/许可只通过契约集成。

## 1. 路线

合计约 35–51 人日，是包含安全/账务/硬件适配的初步估计，不是保证完成日期。2 名开发加测试可并行 P2/P3、P4/P5；平台硬件、支付资质或许可证决策可能形成外部等待。不要因“只是中转站二开”把它压成几个登录按钮的工作量。

### 本版必须交付

- 官方登录、官方模型授权、明确额度与并发规则。
- 自定义服务商的一次性云激活、默认单机、管理员生成/查询/撤销/换绑。
- 三种协议、端口/地址、模型手填/发现、本机安全凭证。
- 所有 AI 调用入口的统一门禁与撤销传播。
- 精确计费规则与幂等结算；真实付费未开通时保持充值关闭，不能假收款。
- 窄窗口/键盘/主题/双窗口/升级迁移与离线行为。

### 可后置

团队/学校多席位购买、自助高级风控换绑、云端教师面板、第三方企业SSO、远程Web激活、硬件attestation全平台保证、更多原生模型协议和分销体系。若严格硬件证明是业务硬门槛，应在 P0 收紧支持平台，不能将其作为“后置”却仍宣传已完成。

## 2. 与 Claude 并行工作约定

1. 先共享 `API-CONTRACT.md`，确认 Gateway 注入位置和 accessRevision 事件。
2. 教学开发保留课程状态、行队列、代码虚影、结构化展示逻辑；账户开发不重写这些文件。
3. 账号团队先用 fake 教学 consumer 验证接口，教学团队用 test-only entitlement 测试，不把放行 stub 进生产。

5. 本轮不向 Claude 所在外部会话自动发送消息；以上文档是可交付协作材料。

## 4. 授权码、设备和离线测试

| ID | 场景 | 期望 |
| --- | --- | --- |
| L01 | 两台电脑并发兑换同一码（两个应用副本） | 一个license/binding成功，另一个拒绝，无双席位 |
| L02 | 事务提交后断网/签名失败，重试 | 同request恢复同结果，不再消耗码，不返回别人的设备凭据 |
| L03 | 过期、废止、已用、错误码/撞库 | 稳定错误、分层限速、日志无码 |
| L04 | 重放challenge、换purpose、改body、公钥替换 | 拒绝；不能把renew proof用于transfer |
| L05 | 复制配置+lease到另一电脑 | 本机信号/密钥不匹配，不能请求或续租 |
| L06 | 同电脑升级/网卡变化/USB变化 | 无误换绑；主板/密钥丢失进入恢复流程 |
| L07 | 系统UUID为零/重复、硬件不支持、虚拟机克隆 | 不误称硬件证明；严格策略拒绝，普通策略显式处理 |
| L08 | 撤销在线/离线设备 | 在线按校验策略失效；离线最晚lease到期，后台显示该边界 |
| L09 | 首次无网络、已激活断网、lease过期、时钟回拨 | 首次拒绝；剩余lease内按策略允许；到期/异常需联网 |
| L10 | 同机重装密钥丢失 | 不凭UUID直接认领，账号/恢复证明/管理员恢复 |
| L11 | 换绑旧设备保持离线 | 宽限重叠明确；严格单机需交还或等待旧lease过期 |
| L12 | 撤销/恢复/签名kid轮换/旧客户端 | revision与密钥链正确；不接受过期/错误issuer/audience |
| L13 | 自定义未登录但已授权 | 可用BYOK，不访问官方模型；可选绑定账号不改余额 |
| L14 | 激活码导出中断/管理员重复生成 | 批次幂等策略明确，不能无限重放生成新码 |
| L15 | 已收到撤销后断网、恢复旧缓存 | 不能重新放行；需更高 revision 的有效云恢复 |
| L16 | online_required 连续请求/排队/网络故障 | 每次实际出队都重新校验；不复用 15 分钟缓存，不预取，不离线放行 |

真实性说明：没有硬件证明不能用“本地报告 hardware-backed=true”当验收。P0 应记录平台型号、API返回、密钥不可导出证据、恢复行为；只有云验证链通过才标记 attested。

## 5. 协议与数据测试

- 三协议分别测试正常、UTF-8跨chunk、SSE多事件/空事件/结束事件、取消、超时、401/403/429/5xx、usage缺失、结构化输出不支持。
- API base 带端口、已有路径、完整operation URL、尾斜线、IPv6 localhost、模型ID大小写、不实现models接口。
- 密钥不能出现在日志、崩溃报告、localStorage、工程文件、同步配置、可逆摘要；删除profile和凭据策略一致。
- 恶意endpoint userinfo/query/metadata、跨源302、代理证书异常、DNS变化及私有CA规则。
- 本地HTTP模型仅用户主动配置；公有HTTP拒绝，内网HTTP要求明确策略。
- BYOK抓包确认仅目标供应商收到代码/key，Nodu控制面只收授权必要数据。
- 官方账号token不会被添加到BYOK header；供应商key不会发给官方oauth/许可接口。

## 6. 并发与计费测试

| ID | 场景 | 期望 |
| --- | --- | --- |
| B01 | 两窗口两设备同时请求，限额2 | 云端合计最多2个受控槽，不是每连接2个；上游实际生成的严格界限按渠道控制能力验收 |
| B02 | 流式响应长时间存活 | 流结束前slot不释放；owner/heartbeat正确 |
| B03 | worker crash、Redis断开、slot TTL到期 | 不无限超发；失联请求隔离占位，确认终止/硬截止前不复用槽；账务可恢复 |
| B04 | 同request网络重试/不同body复用key | 一次逻辑结算；不同body conflict |
| B05 | 接受请求后改价 | 保留原price version，新请求才用新价 |
| B06 | cache含在prompt总数、thinking含output | 非重叠token桶，不重复收费 |
| B07 | 发送前失败/首token后失败/主动取消 | 已发生消耗按策略核算，未消费预占释放，不承诺取消免费 |
| B08 | usage缺失/延迟账单 | pending reconciliation，有封顶/时限，不记成成功零费 |
| B09 | 并发预占超过余额/预算 | 无负余额竞态；数据库原子更新/锁保证 |
| B10 | webhook重放/金额错/签名错/回调乱序 | 不重复充值，错款不加额，冲正可追溯 |
| B11 | 管理员手调余额/许可证退款 | 理由、RBAC、审计和关联订单齐全 |
| B12 | 上游切换/重试多个attempt | 所有attempt可追溯，终端不会看到无提示替换后的回答 |

压测至少包含两个应用副本和共用数据库/Redis；不能只在单进程mock内声称分布式限流有效。使用假上游做大量故障测试，真实模型仅小样本协议/usage核对，避免不必要花费。

## 7. AI 集成与 UI 测试

- 未启用时：新建工程、编辑、编译、下载、串口、纯函数/AST本地检查仍可用；AI只显示启用动作。
- 激活/登录后：教学、提问、自动逐行、整步AI审阅、provider测试均走gate；任何旧直连调用不能绕过。
- 凭证/许可失效时：停止新请求、清理排队、取消在途并拒绝迟到展示；编辑内容、课程进度、下载不受影响。
- 测试关闭侧栏、隐藏虚影、暂停教学是三个不同动作；账户退出不能意外复位MCU。
- 设置弹窗：深浅色、980×720窗口、窄侧栏、200%缩放、键盘、Esc、焦点恢复、读屏标签。
- 主页不新增常驻解释、余额提示或二级标题；错误有短行动说明，禁止中点拼接说明。
- macOS arm64/macOS x64/Windows x64各用签名/打包版验凭据和硬件绑定；无对应机器就列待测，不用交叉编译冒充真机验收。

## 8. 上线与回滚门槛

1. 锁定上游源码/许可/镜像/SBOM；确认云端二开的源码提供或商业许可路径。
2. P0硬件矩阵与设备保护等级真实，支持平台清楚。
3. 账号登录不包含管理员/upstream token；gate无法从正常RPC旁路。
4. L01/L02、B01/B04/B09/B10是阻断发布项。
5. 密钥泄漏扫描、日志脱敏、备份恢复、过期lease和kid轮换演练通过。
6. 付费沙盒通过后再开真实支付；源码/提示词默认不留存，隐私与恢复规则可访问。
7. 新版客户端小范围灰度，服务端保留兼容版本与开关；回滚不擦掉新license/账本，不降低已撤销权限。
8. 发布报告分别写实现覆盖、自动测试、本机实测、其他平台待测、真实模型验证，不写笼统“全部正常”。

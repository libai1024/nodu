# 对话功能逐项对照：Nodu / Cursor

日期：2026-10-25。Nodu 基线 `72aa806`；对照本机 Cursor **3.24.12 的 IDE 侧栏**。范围为会话管理、输入框、消息操作、引用、模型选择和恢复行为，不把整个 Cursor 的工具执行能力视作现有 Nodu 功能。

## 补充纠正：IDE 内的常驻会话列表

用户指出后重新实测：本机 Cursor 3.24.12 聊天标题栏最右侧的 **Toggle Agents Side Bar** 按钮会展开右侧常驻列表，AX 名称为 **Unified agents sidebar**。列表与聊天正文并排，含搜索、新建、日期分组、草稿/完成状态和当前会话；并非独立 Agents Window 才有此布局。此前只检查历史时钟入口，漏查了这个按钮。

历史浮层与常驻会话栏是两种呈现，不能以实现前者宣称已完成会话导航对齐。提交 `d97345a` 已实现紧凑浮层及视觉调整；本次后续实施补上了**可折叠的右侧常驻会话栏**，搜索、新建、日期分组、草稿识别和当前会话均接入真实数据，展开状态持久保存。官方 [IDE 发布说明](https://prod.cursor.com/docs/release-notes/ide) 也分别描述 agents sidebar 与 chat history picker；其中 3.25 的新版行样式不能套用于本次 3.24.12 的实机观察。

## 证据与边界

- **实机**：检查历史按钮、日期分组、搜索框、条目操作、归档入口、连续新建、关闭标签、原草稿恢复、模式和模型菜单。前一轮已实测终端整段/选区引用。没有发送 Cursor 模型请求，也没有删除、归档或重命名用户的真实对话；这类条目只确认了菜单入口。
- **官方文档**：[Prompting agents](https://cursor.com/docs/agent/prompting) 覆盖 @、图片、模型和上下文用量；[Agent overview](https://cursor.com/docs/agent/overview) 覆盖排队、运行中补充和搜索；[IDE release notes](https://prod.cursor.com/docs/release-notes/ide) 覆盖旧消息编辑、分叉和表格呈现。Agents Window 的跨会话全文检索不冒充 IDE 历史弹层的实测行为。
- **Nodu 源码与行为测试**：检查 store、model、header、history、composer、message、context picker 和相关事件测试。Cursor 未实测的存储上限、重试内部恢复点、各类附件采样时机，均不据外观推断。
- UI 继续遵守用户约束：短名称、图标、就地操作、自实现菜单；不增加常驻提示、教程段落或示例占位句。Cursor 自带的提示文案不照搬。

## 升级顺序与验收标准

第一组是会话工作流：稳定会话 ID，标题/草稿名、可折叠常驻会话栏与紧凑历史浮层、多标签、关闭/重开、重命名、置顶、归档/恢复、删除和导出。验收应覆盖“新建 A → 输入但不发送 → 新建 B → 从历史回 A → 草稿和引用一致 → 关闭 A 标签 → 重开 A”。归档和关闭不删除记录，搜索与切换不改变更新排序，不允许固定缓存上限静默吞掉需要保留的历史。

第二组是消息上下文：原位编辑旧消息、取消编辑、按原附件重发、后续消息/模型记忆同步截断、分叉、真正的 @ 候选、当前会话查找和完整 Markdown。重点验收 UI 显示、实际请求和持久历史三者一致。引用源内容发生变化时，已发送消息仍对应原快照。

第三组是会话配置与运行：会话模型、默认模型、模式与会话身份解耦，再做运行中排队、跨会话继续生成、独立停止及状态提示。教学进度仍是 Nodu 的项目能力，不能用切换 Ask/Teach 隐式丢失它，也不能把新建聊天等同于重置教学任务。

图片、语音、上下文用量、自动压缩和完整工具执行放在上述基础工作流之后；只有真实支持时才出现对应入口。

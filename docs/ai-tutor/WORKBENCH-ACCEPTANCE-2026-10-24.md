## 设计依据与交互约定

参考 [PyCharm 2026.2 Welcome screen](https://www.jetbrains.com/help/pycharm/welcome-screen.html)、[IDEA 新建项目](https://www.jetbrains.com/help/idea/new-project-wizard.html)、[IDEA 通知](https://www.jetbrains.com/help/idea/notifications.html)、[通知类型设置](https://www.jetbrains.com/help/idea/settings-notifications.html)。采用其项目优先、最近列表、搜索、明确动作以及反馈分级；保留 Nodu 品牌、颜色、图标和原组件，不照搬商标或添加 AI 启动提示词。

- 默认 960×640，最小 760×500；侧栏只保留项目、参考项目及主题切换。新建使用现有芯片表单，IDE 内其他入口仍使用原弹窗。
- 禁止营销口号、常驻解释、冗余二级标题、以“·”拼接的注释文案。空态只提供新建、打开；参考项目由侧栏进入。搜索框仅显示“搜索项目”。
- 参考项目只显示名称、芯片与创建副本操作，不把 README 长段落、提交号或操作说明塞进列表。内置 board-api 显示为“K210 板端接口”，源码名称与许可不改。
- 反馈分级：字段错误在表单附近；列表加载失败在当前区域提供重试；打开、复制和移除操作失败使用右下角可关闭通知。通知不抢焦点，错误不自动消失，关闭后回到搜索或新建按钮。
- 原生目录选择、未保存等必须作决定的场景沿用原弹窗。不为成功打开、切主题、点击菜单新增确认或成功通知。本次未扩展全应用通知中心或系统通知权限。

## 代码验收和修复

| 问题 | 修复与结果 |
| --- | --- |
| 项目列表拦截 Enter、Tab、Space | 仅处理方向键与 Home/End；实际 Cmd+F、Tab、Enter 打开成功 |
| 获取默认项目目录或空参考列表后停在加载态 | 在成功分支先结束 loading，避免 effect 清理使 finally 丢失；生产组件回归覆盖 |
| 重复点击、忙碌中切页 | 请求互斥，内联新建 busy 信号同步禁用返回及导航 |
| 焦点刷新覆盖操作错误 | 列表错误与操作错误分开，焦点刷新不抹去失败通知 |
| 复制失败的“重试”只重新加载列表 | 操作错误改可关闭通知；真正加载失败保留重试 |
| 选择目录拒绝造成未处理 Promise | 捕获错误、释放 busy、就地显示；卸载后不再打开工程或调用父组件 |
| 空结果留下占空间的空列表 | 无结果不挂载列表，让空态在剩余区域内布局 |
| 搜索出现双重边框、位置文字压住文件夹按钮 | 实际应用全局 device.css 优先级比原覆盖更高；限定工作台样式作用域并复验。夹具同步加载全局控件样式，避免仅夹具正确 |
| 内联创建取消后焦点丢失 | Esc/取消返回，恢复搜索或空态新建按钮；忙碌时不退出 |
| README 直接显示导致长说明和中点标题 | 隐藏摘要，修正内置接口示例显示名，缩紧参考列表 |

架构保持：Electron 主进程只管窗口路由；Theia contribution 装配服务；Launcher 负责视图；项目服务负责最近项目与副本；NewProjectForm 复用既有创建协议。未复制创建后端、未引入新的 UI 框架或运行依赖。

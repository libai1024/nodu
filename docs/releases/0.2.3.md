# Nodu 0.2.3 整合候选

日期：2026-10-29。状态：候选构建，尚不是完整跨平台正式发行。最新正式版保持 v0.2.2。

## 整合内容

- Keil 5：为原生 STM32F103C8T6 工程生成 AC5/AC6 项目，共享现有源码，文件菜单更新、设置中可选择自动维护。
- DACIR：72 MHz HAL 模板、ST-LINK 连接和目标状态处理；已有外部目录工程记录工作频率。
- ESP32 C3/S3：仿真配置与编译产物导出；Windows 离线环境及 Arduino 兼容性测试证据。
- Windows STM32 专用发行：便携数据目录、NSIS 安装器、离线 ST-LINK 驱动文件。
- 串口：修复长消息被通用参数长度限制误拒绝；保持单次 64 KiB 上限。
- 桌面生命周期：应用退出后清理其后台服务，避免遗留串口占用。

原 main 工作区改动先提交为整合检查点；codex/dacir-link 已提交历史原本就是 main 的祖先，其未提交代码通过独立快照分支合并。原工作区没有被重置或删除。大型本地工具链、缓存、已构建应用不进入 Git，测试脚本和选取的证据进入源码仓库。

## 安装包范围

| 目标 | 本轮状态 |
| --- | --- |
| Windows x64 STM32 便携 ZIP / 安装 EXE | 已生成并通过隔离验收；只包含 STM32 离线环境，验收与文件摘要记录在随包 manifest |
| Windows x64 完整版（含 Arduino） | 不满足正式发布门槛：Arduino 资源清单仍为 releaseReady=false，Windows Arduino 语言工具也尚未完整交付 |
| macOS arm64 完整版 DMG / ZIP | 首轮本机缺少发布用 STM32 工具包；本地 dev 工具包不能替代。Arduino 分发材料校验同样未通过 |
| macOS x64 / Universal | 缺少 Intel 发布输入，首轮在 WASI 工具包校验处停止；还缺对应 Arduino 离线发行材料 |
| Linux | 当前应用打包器未实现 Linux 发行目标，本轮不宣称提供 Linux 安装包 |

Arduino 对应材料清单有 25 个组件，其中 20 项仍未完成交付覆盖，不能通过更改 releaseReady 标志或跳过校验制作正式完整包。详见[对应源码材料记录](../design/esp32-arduino-release-sources-20261027.md)。未通过校验的目标不上传伪装成可安装的占位文件，也不将旧版安装包改名为 0.2.3。

Windows STM32 候选仅供检查该发行范围，不承诺 ESP32/Arduino 开箱使用。Mac ad-hoc 签名、Windows 未签名的现状也不等于完成商业签名与平台公证。

## 验证与限制

合并后必须完成 TypeScript 编译、原生嵌入式服务回归、Keil/桌面生命周期/打包脚本测试。Windows 候选需要从干净的源码提交在 D 盘构建，并核对生成包中的版本、提交身份及资源。

已有实测：[Windows ESP32](../evidence/windows-esp32-20261029/README.md)、[Keil 集成](../evidence/keil-integration-20261028.md)。其中 ESP32 只有软件和模拟/虚拟串口证据，没有实体 C3/S3 烧写验收。网络下载与 Arduino IDE 2.3.7 profile 格式兼容问题仍然存在。

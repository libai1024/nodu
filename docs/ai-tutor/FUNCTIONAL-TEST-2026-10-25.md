## 本地故障注入实测

使用独立 localhost HTTP/SSE 服务，不发送 GLM Key。实测模型为既有 `ui-preview-1`。本轮启动服务并在收尾停止。

| 场景 | 观察结果 |
| --- | --- |
| 首次中途断流 | 保留已输出文字，标记“回复中断”，提供重试及错误详情 |
| 重试同一问题 | 完整恢复 Markdown、列表、源码引用和代码块 |
| 代码块操作 | 21 行代码可展开/收起；复制显示“已复制” |
| Shift+Enter | 输入框内换行，不发送 |
| 慢速流式输出 | 显示停止按钮，禁用模式切换和新对话 |
| 生成期间再次按 Enter | 没有增加请求 |
| 停止生成 | 保留部分回复并标记“已停止”，输入草稿完整保留 |
| 已有草稿时修改历史问题 | 拒绝覆盖，提示先保留或清空草稿 |
| 清空草稿后修改历史问题 | 仅回填输入框，不自动发送 |
| 历史切换与刷新 | 没有重放网络请求 |

服务最终计数：请求 3，中断场景 2（首次中断、第二次完成），慢速场景 1（取消）；完成 1，中断 1，取消 1。上述操作后计数没有额外增加。

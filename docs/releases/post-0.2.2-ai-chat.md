# AI 对话侧栏落地与验收

日期：2026-10-24。基线：`af66162`。工作分支：`codex/nodu-02-integration`。

## 范围与交互

按已确认的 Cursor / Devin / Codex 参考方案整理对话侧栏，沿用 Nodu 的主题变量、字体、圆角、图标与整体 IDE 布局。

- 用户消息靠右，使用浅主题色气泡；AI 回答靠左，不增加头像、重复角色标题和外层卡片。
- 标题栏统一为新对话、历史与更多操作。历史是真实的本地记录，按工程身份和教学/提问模式隔离，支持重新打开；清空当前对话需要确认。
- 底部输入区集中当前文件、固定文件/选区附件、模式、模型和发送/停止。模型菜单按供应商分组，数量超过 8 个时提供搜索；未配置和切换失败都有明确状态。
- 已发送问题下的灰色文件标签保留本次上下文的路径与行号快照，切换编辑器不会改变旧消息的标签。点击仍经过工程文件授权。
- Markdown 仅渲染受控语法，代码块支持轻量语法着色、复制、横向滚动和长代码折叠；普通问题保持纯文本。拒绝原始 HTML、危险协议和越界文件引用。
- 断流保留已收到的文字，回复下以灰色短文案和重试操作显示。连接状态靠近输入区，诊断详情按需打开，不增加醒目的告警卡片。
- 向上阅读时暂停自动跟随；“最新回复”回到底部。草稿、阅读位置和消息展开状态按会话隔离；输入法组合输入和忙碌态不会误发。
- 动态计划草案保留确认、修订、取消。已接受任务与固定课程的步骤、自查和重置统一进入跨编辑器任务浮窗，不在聊天顶部重复展示进度条。

## 数据与后端边界

- 固定上下文最多 6 项，含当前文件总计 64 KiB。附件经后端有界读取、路径授权与复核；Python 文件仅用于提问，不送入 C 教学检查。
- 会话记录设有数量、消息数和字节预算；草稿合并保存，切换/发送/关闭前保存。恢复只同步有界的普通聊天上下文，不自动重发请求、不重放目标修改或教学动作。
- 双窗口写入同一历史时复制会话，避免相互覆盖。重试使用原请求的源码快照，不覆盖当前新草稿；教学版本或源码变化后禁止套用旧审阅结果。
- 网关请求按最终 JSON 的 UTF-8 字节限制为 1 MiB，避免 64 KiB 附件被旧的字符限制截断；超限直接提示减少附件或新建会话。
- 用户消息中的附件标签仅额外保存路径、类型和行号，不在标签字段重复保存源码。持久记录执行已有敏感值过滤。

## 本次发现并修复

1. 停止按钮在点击期间变成发送按钮，浏览器默认提交导致草稿意外发送。两个按钮改为独立实例，显式 `type="button"`，取消点击默认行为；真实 Electron 复验停止后草稿原样保留，服务器请求数没有额外增加。
2. 附件菜单切到异步文件列表时焦点落回页面，导致键盘导航丢失；现在保持在菜单内。
3. 重试或编辑问题产生的新错误被旧失败消息吞掉；只去重相同错误，保留新的失败原因。
4. 固定附件与旧工程引用读取预算冲突；保留旧 C 引用的 32 KB 边界，新增上下文读取独立使用 64 KiB 预算。
5. 同工程连续重连在临时句柄清空时误判为新工程，清空消息和草稿；现在使用稳定工程身份并保留重连缓冲区。
6. 浏览器存储配额不足时，重选历史读回旧磁盘内容；现在未保存记录优先读最新内存，保留有界的 40 条待保存会话并显示轻量“重试保存”，不会触发重连或模型请求，也不会静默淘汰未保存内容。
7. 桌面日志发现标题栏贡献项缺少稳定 React key；补回 key，避免工具栏列表警告。模型菜单优先聚焦当前已选模型。
8. 查看已有历史后退出也会触发跨窗口复制，产生重复问题和空会话；持久化改为语义幂等，只有真实内容变化才创建副本，新空输入区不加入历史。此前测试产生的重复记录留在隔离 profile 中，没有删除记录掩盖问题。

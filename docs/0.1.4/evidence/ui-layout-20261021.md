对象：`main`（`6a2ca36`）之上的 UI 改动。方向来自 [HANDOFF §5](../HANDOFF.md)。
验证环境是浏览器目标加内存模拟板（`NODU_DEVICE_MOCK=1`），**不是** Electron，也不是真板。

## 2. 与 HANDOFF 候选方向的对应

- 文件菜单集中新建 / 打开 / 最近 / 示例 / 保存：**项目 ▾**。示例、最近的文件、文档文件夹是从“文件”菜单链接过来的，不是复制。
- 突出运行 / 停止和单一设备入口：**运行 ▾**（带变体）、停止、设备入口。图像工具原本就在帧缓冲面板内，未动。
- 区分电脑文件与板端文件、区分保存语义：项目 ▾ 里是“保存到电脑”；运行 ▾ 里是“运行（开发板内存，不保存）”“保存到开发板…”“设为开机脚本（boot.py）…”“发送其他文件到开发板…”；专业模式的“开发板文件”与资源管理器分开。
- 简 / 专切换移入“查看”：已移入 ⋯ 与“查看”。简洁模式默认收起三个面板（原本如此）。

这些只是对候选方向的一种落地，用户尚未逐项确认。

**按钮数量没有减少。** 顶部可见控件改前 9 个（文件、运行、停止、设备、控制台、视觉、主题、简、专），改后仍是 9 个。
收进去的是主题与简 / 专，新增的是项目与运行两个下拉。

## 3. 实测结果

环境：Node 24.21；前端用 esbuild 开发模式重新打包；4190 端口，模拟板；Browser 窗格视口 1440×900、1280×800、1100×700、980×680。

| 项 | 结果 |
| --- | --- |
| 简洁模式工具栏 | 9 个控件，`aria-label` 为：项目菜单、运行、更多运行方式、停止、设备与端口、文件列表、串行终端、帧缓冲、更多 |
| 项目 ▾ | 新建文件 / 打开… / 示例 ▸ / 最近的文件 ▸ / 文档文件夹 ▸ / 保存到电脑 / 另存为…；三个子菜单都已链接，内容与“文件”菜单同源 |
| 运行 ▾ | 4 项；未连接时后 3 项禁用；连接模拟板后 4 个命令的 `isEnabled` 均为真 |
| ⋯ | 切换深浅主题、简洁模式 ✓、专业模式、命令面板、设置、关于 Nodu；用合成的 mousemove + mouseup 事件点专业模式后布局切换成功。预览工具的 click 没有触发切换（原因未深究），所以没有做过真实鼠标点击 |
| 查看 | 布局组含简洁模式、专业模式、文件列表、串行终端、帧缓冲，`isToggled` 与实际状态一致 |
| 面板开关 | `aria-pressed` 与图标（`layout-*` / `layout-*-off`）、提示语随状态变化 |

| 启动时已在出帧 | 刷新页面后帧缓冲在布局完成后展开一次，之后手动关闭不再弹出。修复前观察到刷新后一次性标志已被消耗（`autoRevealed.vision` 为真），当时没有记录面板是否展开；“被启动布局收回”是按代码推断 |
| 专业模式 | 左侧栏为资源管理器 / 开发板文件 / 搜索；未连接时“开发板文件”显示“未连接设备”和“连接设备”按钮 |
| 开发板文件 | 连接后首次显示该标签才列目录；切走再切回不重复列；目录输入框在弹层与视图间保持同步 |
| 保存到开发板 | 输入框预填当前文件名；确认框文案“将当前内容（32 字节）保存为板端 ui_check.py，同名文件将被覆盖。”；按钮“取消 / 保存”；日志“已写入板端 ui_check.py（默认存储）。” |
| 保存后刷新 | 有列表时调用 `listFiles('/flash')` 一次；无列表时不调用 |
| 窄宽度 | 980×680（Electron 最小窗口）下简洁与专业模式工具栏均无重叠、无溢出，当时项目名为 `ws`。长项目名在 1100 px 视口测试：按钮 200 px，名称显示省略号。≤900 px、≤700 px 的媒体查询规则未测（Electron 到不了这个宽度） |

“本地文件不被修改”只从代码路径判断（命令只读编辑器缓冲），没有单独实测。

## 4. 核对中发现并修复的问题

第 7 行是用计算样式确认的；其余是读代码发现的，修复前没有逐条复现。修复后的行为都在页面上实测过，除了第 4 行（只有单元测试，板端行为未验证）和第 8 行（只做了语法检查，驱动没有运行，它需要真板和 4187 端口的 Chrome）。

| 问题 | 处理 |
| --- | --- |
| 连接时“开发板文件”标签在后台，不会列目录，显示标签后也不列 | 显示时（`onAfterShow`）或连接后可见时，每次连接只列一次 |
| 专业模式下设备弹层里还有一份板端文件区，与视图可能不一致 | 专业模式下保持挂载但隐藏 |
| 保存到开发板后已显示的列表不更新 | 成功后刷新已有列表 |
| 文件名可写成 `boot.py.`，可能绕过启动文件二次确认 | 拒绝以点结尾的名字；规则抽到 `common/` 并加单元测试。这一点是按 FAT 行为推断，未在板上验证 |
| 弹层与视图各有一个目录输入框，切目录后互相陈旧 | 输入框随 `model.directory` 同步 |
| 启动时已在出帧，自动展开的一次性机会被启动布局耗尽 | 布局完成前不消耗 |
| `.nodu-heading-status-only` 从未生效（被更高优先级规则覆盖） | 删除，画面无变化 |
| `measure-stream.cjs` 选 `[aria-label="专业模式"]`，新界面没有这个按钮 | 找不到时改用 `scope.layout.pro` 命令 |

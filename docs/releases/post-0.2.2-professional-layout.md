# 专业模式布局落地与验收

日期：2026-10-24。基线：`b05b846`。工作分支：`codex/nodu-02-integration`。

## 设计范围

按用户确认的草图整理布局，继续使用 Nodu 已有字体、主题 token、圆角、图标和设置组件。草图中 AI 对话标题下重复的任务进度条不保留。此次没有更换品牌视觉，也没有变更教学、编译或下载后端。

- 自定义标题栏合并项目搜索与专业工具栏，减少原来的第二行工具条。搜索实时避让工具栏和系统窗口按钮。
- STM32 操作顺序为设备、编译、烧录、运行（编译并烧录）、停止、AI 教学、更多、设置。沿用极简模式的锤子、下载和运行图标及动作颜色。
- K210 保留运行到开发板内存和停止；板载文件、开机脚本等原操作收进“更多运行方式”。ESP 保留项目任务入口，不引入 STM32 下载命令。
- 项目入口放在左侧品牌图标，左侧继续使用现有工具栏和文件树。设置固定在标题栏右端，与极简模式共用同一设置组件。
- 按用户后续确认，两种模式的设置都位于窗口标题栏最右侧同一坐标；不再在标题栏与编辑器标签行之间跳动。没有自定义标题栏的平台，两种模式共同回退到编辑区右上角。
- 按用户后续确认恢复专业模式右侧常驻工具栏；内容收起时图标入口仍保留。K210 与 STM32 都可打开帧缓冲，也都可从“更多”打开/收起右侧栏。STM32 摄像头传输协议与设备接入尚未设计，本次不增加硬件能力。
- AI 侧栏保留一行标题、对话和底部输入区。动态计划草案仍可确认、修改、取消；接受后的步骤由跨编辑器任务浮窗统一管理。静态课程独有的自查、步骤选择和重置保留。
- 去除空白对话中的大图标和示例提问；模式、模型、发送操作集中在输入区底部。连接错误、重连、取消生成和密钥配置保留。
- 底部沿用构建与下载、串口监视、终端。首次进入专业模式不强行展开；模式切换保留已有面板状态和编辑器实例。
- Windows/Linux 原生标题栏隐藏 Theia 顶部面板时保留独立工具栏行，避免操作入口丢失。

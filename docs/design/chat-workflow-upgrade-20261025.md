## 范围与数据

终端范围使用 Theia `TerminalWidgetImpl.getTerminal()` 的公开 xterm 选区范围，转为一基行号；结束位置在下一行第零列时不包含该行。软换行可能把多个缓冲行合并成一行选区文本，校验允许该情形。选区范围不可获取时拒绝添加，不默默替换为其他输出。整终端入口始终从最近 200 行截取并去除尾部空行，终止行与实际内容一致。

固定引用与历史使用同一份请求快照。终端来源标识只用于内部去重，不作为路径读取，不在界面显示。终端文本受已有 6 项／64 KiB 附件限制及工程授权约束；已识别凭据在附带前隐藏。多会话切换仅恢复会话，不重发历史请求或重新执行教学任务。

同一终端的不同选区可同时附带；重新引用相同选区只替换该选区，刷新整终端引用保留已选片段。整终端引用目前仍为添加时的有界快照，不宣称与 Cursor 的后台上下文采样时机完全一致。快捷键沿用 Nodu 编辑器的 `Ctrl/Cmd+Alt+L`；Cursor 本机显示的是 `Cmd+L`。未模拟依赖 shell integration 的命令输出块悬停入口。

本轮没有加入自动文件编辑、工具执行时间线、变更批准、检查点回滚或并发 Agent。这些需要执行层支持，不能用静态界面代表已实现。

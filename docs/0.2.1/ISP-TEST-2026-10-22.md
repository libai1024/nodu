# STM32F103 串口 ISP 实测记录

2026-10-22，macOS arm64，STM32F103C8T6，CH340 `/dev/cu.usbserial-31230`，PA9/PA10，ST-LINK 保持连接。用户亲自切换 BOOT0 并复位。本报告记录帮助功能开发之前已完成的硬件测试。

## 修复

- 串口借出状态持久保留为 `lent`，下载期间拒绝打开、关闭、发送，避免其他窗口抢占或覆盖原监视器。
- ROM 等待前及轮询中响应取消；只读备份可停止，开始写入后完成写入与校验，避免普通停止留下半片程序。
- 识别后使用 stm32flash `-c` 接续已同步的 Bootloader，避免重复 INIT；重复下载无需每次复位。
- 写入完成记录为 `awaitingBootRestore`，不将尚未恢复 BOOT0 的程序误记为运行中。
- ISP 成功后打开所选串口，即使此前监视器关闭；修复串口打开事件与面板切换的时序问题。
- 恢复启动阶段禁止发送，收到有效完整文本行后自动收起引导；ROM 控制字节及乱码不视为启动输出。
- 子进程输出同时按 CR/LF 分行，让 stm32flash 进度实时到达前端。

## 实物结果

| 项目 | 结果 |
| --- | --- |
| 等待 ROM 时取消 | 2 秒内结束；串口恢复，PING/PONG 通过；未进入写入 |
| 未切 BOOT 的超时 | 实际等待 60 秒，返回 romTimeout；串口恢复，PING/PONG 通过 |
| UI 停止 | 引导收起，串口恢复；不显示取消错误弹层 |
| 第一次 UART 下载 | 15.708 秒，含 64 KiB 完整备份 |
| 第二次 UART 下载 | 6.787 秒，复用备份；此前关闭的监视器自动打开 |
| 第三次 UART 下载 | 6.797 秒，最终代码；自动切换监视器；完成前捕获回读 17.76% |
| 用户 BOOT0=0 并复位 | 收到 NODU UART READY；未点界面按钮，引导自动收起 |
| 运行后收发 | PING/PONG、分包中文“中文串口测试”通过，115200 8N1 |

三次均写入 10088 字节，完整回读 SHA-256 为 `0ffc0b8a0d48d363c24b6fb76c678c38825bdb0d33f567d6aa9bd014a04359a2`，与固件一致。芯片 ID `0x410`、Flash 64 KiB、UID `0671ff373634574e431e5512`。

此次 UART 备份位于 `artifacts/isp-e2e-20261022/device-state/stm32/backups/410-0671ff373634574e431e5512/20261022-150201/flash.bin`，65536 字节，SHA-256 `bb030999f966a24ca645ffb4e369785cecf55d2bd1821c7d04481a2da2249bcf`。这是上轮串口测试固件的备份，元数据的 factory 标记表示该数据目录内首次备份，不能解释为用户原始程序。最初的用户程序备份仍保留在 `artifacts/f103-ui-20261022/device-state/stm32/backups/`。

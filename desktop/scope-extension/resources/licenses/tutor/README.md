# C structure checker

The nodu-tutor sidecar includes tree-sitter 0.27.1 and tree-sitter-c 0.24.2, both MIT licensed. Exact dependency checksums are pinned in desktop/native/Cargo.lock. The two upstream license notices are included alongside this file.

Source: https://github.com/tree-sitter/tree-sitter and https://github.com/tree-sitter/tree-sitter-c

Transitive runtime dependencies tree-sitter-language 0.1.9 and streaming-iterator 0.1.9 are used under MIT; their notices are included. Existing shared Rust dependencies retain the application notices.

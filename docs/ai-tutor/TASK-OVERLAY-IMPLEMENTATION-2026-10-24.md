# AI 教学任务窗实现与验收

日期：2026-10-24。基线：41d54bc，分支：codex/nodu-02-integration。

## 已实现

- 一个工程的教学任务显示为紧凑浮窗：标题、检查数量、当前/相邻步骤、展开全部、暂停/继续、检查、结束。
- 整个主编辑区共用一个 React 覆盖层，独立于单个 Monaco 编辑器；可以跨分屏移动。切文件保留位置及展开/编辑状态，不复制窗口。默认避开顶部标签栏，尺寸变化时限定在整个编辑区内。
- 右上 AI 编辑指导控制总开关，AI 菜单中的“任务步骤窗”控制单独显示。隐藏不取消任务。Esc 收起当前操作层或浮窗，不结束教学。
- 步骤标题及文件按钮可打开对应工程文件；当前片段有有效锚点时定位该行，否则定位文件首行。复用后端路径授权和切工程迟到响应保护。完成后跨文件不强制抢焦点，点击“继续跟写”进入下一文件。
- 复用现有逐行/片段检查，检查通过才推进；支持待修改、缺上下文、检查中状态，UI 不自行标成功，也不将代码检查称为编译或真机通过。
- 用户输入新增功能，AI 在现有任务后追加步骤；仅引用已授权文件，每任务最多24步。删除未完成步骤需确认，不改源码，可撤销最近一次删除。已完成历史不可删除，最后一个未完成步骤使用结束任务。
- 新增步骤使用稳定 ID，不因移除重编号；revision 防止另一窗口的迟到模型响应覆盖新状态。删除当前步骤撤回范字并暂停。
- 窗口窄于640px指整个编辑区宽度，不是某一分屏宽度。紧凑状态、菜单、内联添加/删除确认支持键盘访问。

## 本版边界

当前仍是顺序代码教学任务，支持末尾追加与未完成步骤删除，不是完整依赖DAG或任意重排编辑器。构建/下载/硬件验收任务类型、自动拆分任意任务、跨多个已完成文件的证据过期传播仍属于后续设计。拖动位置保留在当前窗口会话内，不承诺跨应用重启恢复位置。教学目标/进度继续使用现有持久化。

## 人工复验

1. 在教学模式生成并确认计划，右上AI菜单打开任务步骤窗。测试总开关和单独开关，进度应不变。
2. 分屏打开两个文件，将任务窗拖过中间分隔线；也可Tab到移动手柄后用方向键移动。点击另一文件，窗口保持原位置。
3. 点击步骤名或文件图标，打开对应文件；已有锚点时定位。步骤不会因点击文件就变成完成。
4. 跟写一个片段，检查通过后进度增加；错误代码或缺上下文不得推进。跨文件下一步点击继续跟写。
5. 更多菜单添加步骤，配置当前服务商后输入新增功能。删除未完成步骤，再撤销；源码应完全保留。
6. 暂停、重载、继续；切换主题、缩小整个窗口、Esc/Tab/Enter操作，检查没有重复浮窗或越界。

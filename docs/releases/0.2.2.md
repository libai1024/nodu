# Nodu 0.2.2

本版集中整合 STM32 HAL C 开发、AI 教学、独立工作台与极简编辑界面。应用版本与仓库 `VERSION` 为 `0.2.2`；Release 标签为 [`v0.2.2`](https://github.com/libai1024/nodu/releases/tag/v0.2.2)。安装包对应的精确源码提交以附件 manifest 的 `sourceCommit` 为准，并与该标签核对。

## 本版内容

- 独立工作台：欢迎页以新建、打开和示例三个图标入口为主，另提供最近项目和设置；支持项目搜索、示例副本、主题与启动选项。“打开项目”使用简洁标签。欢迎窗口固定为 960×680，仅在屏幕可用区域不足时缩小；工程窗口保留原有调整方式。表单错误、操作失败与加载状态分别处理。
- 项目标识与窗口操作：按工程目标显示厂商图标和型号，缺失工程保留身份；提供保留工作台打开项目、文件夹定位和移除记录。修复身份缓存失败影响列表、迟到更新覆盖新状态，以及损坏的旧清单阻止读取有效新目标的问题。
- 极简界面：常驻左侧功能栏、顶部项目搜索、右上角简洁设置，保留深浅主题；底部圆形动作按钮支持长按选择编译、烧录或编译并烧录。
- STM32：HAL C 工程、clangd、固件产物定位、ST-LINK/串口 ISP 配置、构建与烧录进度；修复取消后遗留 BOOT 引导、切换方式无响应及旧构建误用等边界。
- AI 教学：目标计划、下方范字、行/片段反馈、高光批注、文件跳转、暂停恢复和跨编辑器任务浮窗；支持修改步骤。
- K210：保留 MicroPython 运行、REPL、板端文件与相机工作流。

## 已知范围

- AI 评价不能代替编译与真机运行；模型可能给出错误 API，缺上下文时需要核对工程声明。
- F407 SHT30 课程有离线构建与纯函数检查，尚未证明真实传感器通信。
- Windows 的教学纯函数执行暂不可用；Intel Mac 的完整应用验证和 Linux 分发尚未完成。
- 账号、计费、并发控制与电脑绑定授权仍处于 [0.3 设计](../0.3/README.md)阶段。
- 本次不启用 CI/CD。历史工作流已移为停用参考文件，不会随推送自动运行。

# Nodu 极简模式设计草案

2026-10-24。仅设计，未修改产品实现。视觉稿：`concept.png`。图中连接状态、代码与输出仅用于展示布局，不是运行证据。

## 定位

无 AI 的专注编码界面。保留原截图的单工具栏、文件标签、编辑器和状态栏，侧栏默认收起。不出现聊天、教学、任务窗、虚影、推荐问题或 AI 开关。

冷白编辑区、银灰工具栏、石墨色文字与主按钮。品牌黄色限于 logo；活动标签细蓝线。42px 工具栏、30px 标签栏、22px 状态栏；不使用大卡片、虚线设备框、渐变或常驻解释。界面字 13px，代码 15px；正式实现保留字号设置。图中生成器产生的空白行号及语法配色不是实现规范，实际使用 Monaco 正常行号和低饱和度主题。

## 已核对的运行语义

依据当前集成树代码，而非旧版路线文档：

| 操作 | K210 当前 MaixPy 流程 | STM32 当前 C 流程 |
| --- | --- | --- |
| 运行 | 当前 Python 缓冲区，包括未保存内容，发送设备执行 | 保存工程、编译、检查产物、下载 |
| 独立编译 | 无本地 C 编译步骤 | 常驻紧凑编译按钮，无设备也可编译 |
| 停止 | 中断脚本或取消设备操作 | 取消编译/下载事务，不代表停止 MCU 程序；写入阶段遵循现有安全取消 |
| 持久化 | 保存到电脑、保存到设备、设为 boot.py 是不同操作 | 固件写入 Flash；不增加误导性的保存脚本选项 |
| 下载后运行 | 不适用脚本运行按钮 | ST-LINK 与 ISP 按实际流程处理；手动 ISP 需要恢复 BOOT0 并复位 |

代码依据：`scope-workbench.tsx` 的 `runCurrentEditor` 和运行菜单；`nodu-embedded-contribution.ts` 的 `build/run`；`nodu-embedded-model.ts` 的 `build/run/stop`。上述均在 `desktop/scope-extension/src/browser/`。

## 操作分配

- 左侧：logo、项目菜单、编译（仅 C）、运行分裂按钮。取消仅任务进行时出现，结束后撤下；K210 脚本运行期间提供停止。
- 右侧：芯片型号及连接状态、文件面板、输出面板、更多。设备详情、端口、下载方式在设备弹层中。无需选择具体开发板。
- 运行菜单：K210 放设备保存与开机脚本；STM32 放下载方式及下载帮助。菜单文案使用短名称，差异说明按需显示。
- 文件树默认关闭；点击文件图标展开可停靠的窄侧栏。底部控制台可收起并记忆用户选择；K210 摄像头视图放更多菜单，需要时打开。
- 正常编辑时不显示常驻成功提示。编译/下载期间底部左侧显示阶段、真实百分比及细进度线；无真实百分比时用不定进度。完成短暂显示结果，失败保留可点击的错误入口。
- 需用户处理的下载引导使用紧凑弹窗；非阻塞结果使用可关闭的右下角通知，避免重复同时出现多处通知。
- 窄窗口优先保证代码面积；设备型号可截断并提供完整 tooltip，次要操作进更多菜单，编译与运行保持可达。图标提供名称、tooltip、键盘焦点和足够点击区域。

## 生成方式

使用内置 image_gen，原始 Nodu 截图作为结构参考。提示方向：并列展示 STM32 C 编辑态与 K210 Python 运行态；冷白/石墨色、细分隔线、紧凑原生 IDE、无 AI 功能、无营销文案；左侧控制台收起，右侧浅控制台展示脚本输出。最终产品以以上交互规范和可运行组件为准，不从图片推导功能已实现。

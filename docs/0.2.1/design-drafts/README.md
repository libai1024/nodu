# 新建项目设计草稿

2026-10-22，按用户反馈暂停应用代码修改，先提交视觉方案比较。这里是独立静态设计稿，不是已经定稿或接入的产品页面。此前工作树改动尚未作为最终 UI 验收。

打开 index.html 可切换 A/B/C、深浅主题、并排对比和控件状态。SVG 保留可编辑的文字与矢量几何。

| 方案 | 形式 | 优点 | 取舍 |
| --- | --- | --- | --- |
| A | 左侧系列 + 右侧纵向表单 | 接近 IDEA/PyCharm；扩展更多系列容易 | 固定侧栏占用横向空间 |
| B | 顶部四类系列 + 单页紧凑表单 | 四类直接可见；路径够长；视线集中；占用小 | 系列超过六类时需重新设计导航 |
| C | 编辑器内的创建页 | 无模态遮挡；字段和模板展开；扩展空间大 | 简单创建占一整页，入口退出成本更高 |

建议优先比较 B 和 A，当前只有四类系列时倾向 B；这只是建议，等用户选定再实现。

设计约束：芯片选型，不列开发板；窗内只保留标题、四个字段、系列切换和操作，无二级标题、模板解释、名称规则常驻提示或成功祝贺。内容使用真实型号 STM32F407ZGT6 演示；K210、F103 和 ESP32 采用相同结构切换字段内容。

控件：标题 19 px/600，正文 13 px，标签 12–13 px；按钮高 36 px，输入框高 38 px，控件圆角 6 px，弹窗圆角 12 px。创建是唯一实心主按钮，取消是次级按钮，文件夹浏览是图标操作。焦点、悬停、按下、禁用、执行中状态独立设计。蓝色来自现有 Nodu #2F5BFF；深色表面和文字沿用品牌层级。浅色稿用于对比整体视觉，完整对比度和键盘行为在方案选定后实现验证。

交互意图：修改过的名称和路径在切换系列时保留；选择型号不关闭窗口；Escape 取消，Tab 顺序为系列 → 名称 → 位置 → 浏览 → 型号 → 模板 → 取消 → 创建；未满足字段条件时创建不可用，只有提交冲突时在对应字段给出短错误；创建成功直接打开主文件。执行期间不重复提交。

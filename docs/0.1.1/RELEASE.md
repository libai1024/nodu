# Nodu 0.1.1

日期：2026-10-19。状态：**开发基线 / 交接版本**，本地 Git 标签为 `v0.1.1`。四个 npm workspace 与锁文件统一为 `0.1.1`，保留内部 `scope-*` 名称兼容。

## 本版内容

- Theia / Electron 工作台、Nodu 蓝色品牌和简洁 / 专业双布局。
- 新精简工具栏：文件、运行、停止、设备选择集中在顶部；控制台与视觉独立开关，视觉按钮位于最右侧。
- 默认只有编辑器，收起重复入口；切换模式保留未保存文本、光标、浮层草稿和设备连接。
- K210 串口、REPL、RAM 运行 / 停止、文件传输与真实 JPEG。
- ROI、像素、RGB / 灰度直方图、PC LAB、参数复制、缩放和原图导出。
- 固件镜像准备、严格保全与身份读取实现；当前 `DE/E7` 及失败后原件复核证据。
- 按版本归档的交接与技术文档、本地 Git 基线。

## 验证与限制

macOS 原生新布局、30 帧 RAM 相机示例、真实相机预览、控制台和模式保留已验收。固定 Python worker suite 100 项、Node 后端 / 图像 14 项、TypeScript 编译通过；此前 browser / Electron 构建无错误。隔离 E7 候选另有 C ASan/UBSan 与 10 项 Python 诊断测试，未部署或运行硬件。

交接整理只改版本、文档与 Git，不重启现有窗口，不重复真机操作。交接后的离线复核结果见 [validation.json](validation.json)。

- 当前 Flash 身份未通过：首个 `DE` 收到 `E7`，实际 ID 未返回；容量未认证，未完整备份、未烧写。
- probe 失败分支的原件复核尚未自动覆盖；本次手工检查全部通过。
- Windows、STM32 / ESP32 工具链、板卡 / 库包、持久部署、串口绘图器、KPU、仿真和搭芯联动未验收或未实现。
- PC LAB 是解码 JPEG 的近似值，低速快照不承诺连续视频性能。
- 没有安装器、签名、公证、自动更新或完整分发许可验收。
